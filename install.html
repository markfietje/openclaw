Install OpenClaw

Run OpenClaw on your Mac in a few minutes.

Before you start

  • A Mac with an Apple Silicon chip (M1, M2, M3, or M4)
  • macOS 26 or later (Apple Container requirement)
  • About 3 minutes

1. Open Terminal

Press ⌘ Space, type Terminal, then press Return.

2. Install Apple Container

Open the Apple Container releases page, download the latest .pkg file, and double-click it to install. Enter your Mac password when asked.

Then return to Terminal and press Return when the installer finishes.

3. Run the installer

Copy the command below, paste it into Terminal, and press Return:

curl -fsSL https://raw.githubusercontent.com/markfietje/openclaw/main/scripts/apple-container/bootstrap.sh | bash
What this does: downloads the OpenClaw installer, pulls the container image, creates a few small files inside ~/.openclaw/, and stores a secure random token in your Mac's Keychain. The gateway is not started yet — that's the next step.

4. Start the gateway

When the installer finishes, run:

~/.openclaw/bin/openclaw-container.sh run

After that

  • Open http://localhost:18789 in your browser to use the dashboard.
  • Run ~/.openclaw/bin/openclaw-container.sh upgrade to get the latest version later.
  • Run ~/.openclaw/bin/openclaw-container.sh stop to stop the gateway.
  • Run ~/.openclaw/bin/openclaw-container.sh status any time to check whether it's running.
Make the commands shorter

Add these to your shell (Terminal → Settings → Profiles → Shell → Startup → Run command, or paste into ~/.zshrc):

alias oc='~/.openclaw/bin/openclaw-container.sh'

Then you can just type oc run, oc stop, oc upgrade.

I get a "command not found" error

Make sure you opened a fresh Terminal window after installing Apple Container. If it still fails, restart your Mac and try again.

I get a permissions prompt

That's normal. macOS asks for your password the first time OpenClaw sets up the secure token. Type your Mac login password and press Return. The password is not stored or sent anywhere.

How do I uninstall?

Run ~/.openclaw/bin/openclaw-container.sh uninstall. It removes the container and the saved script. Your configuration in ~/.openclaw/ is kept unless you also delete that folder.
